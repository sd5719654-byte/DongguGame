# 동구게임 🎴

4명이 함께 즐기는 카드 벌칙 게임입니다. **휴대폰 가로 화면**에 최적화되어 있고, 인터넷 없이도 실행할 수 있습니다.

## 게임 방법

1. 플레이어 4명의 이름을 입력하고 **번호 1개 / 번호 2개** 모드를 고릅니다.
2. 플레이어들이 뒤집힌 숫자 카드에서 1~10 중 자신의 번호를 직접 뽑습니다. 번호는 서로 중복되지 않습니다.
3. 트럼프 카드 52장을 섞어 2장은 테이블에, 나머지 50장은 덱에 놓습니다.
4. 차례가 된 사람이 테이블 카드 2장 중 한 장을 선택합니다. 선택한 카드와 덱에서 새로 나온 카드의 값을 더합니다.
5. 합계의 **끝자리**가 누군가의 번호와 같으면 그 사람이 벌칙을 받습니다. 끝자리 0은 **10번**입니다. A=1, J/Q/K=10입니다.
6. **벌칙에 걸린 사람이 다음 카드도 직접 선택합니다.** 아무도 걸리지 않으면 별도 팝업 없이 다음 사람 차례로 진행합니다.
7. 총 50턴을 마치면 벌칙 횟수와 순위를 보여줍니다.

게임 진행 상황은 휴대폰에 자동 저장됩니다. `처음으로`를 선택하면 진행 기록을 새로 시작할 수 있습니다.

## APK 다운로드 (휴대폰에서)

1. [GitHub의 Actions 화면](https://github.com/sd5719654-byte/DongguGame/actions/workflows/build-apk.yml)을 엽니다.
2. `동구게임 APK 만들기` 작업에서 **초록색 체크(성공)**가 표시된 가장 최근 실행을 누릅니다.
3. 화면 아래 **Artifacts**의 `DongguGame-APK`를 눌러 압축파일을 받습니다.
4. 압축파일을 풀고 `app-debug.apk`를 실행해 설치합니다. 안드로이드가 설치 허용을 요청하면 확인합니다.

자동 실행이 없다면 **Run workflow → Run workflow**를 눌러 새 빌드를 시작할 수 있습니다. 이 APK는 휴대폰 설치 테스트용 디버그 빌드이며, 플레이스토어 배포용 서명 APK는 아닙니다.

## 개발 및 테스트

- `web/`: 기존 동구게임 웹 버전의 HTML/CSS/JS 원본
- `android/`: 웹 버전과 동일한 게임 파일을 탑재하는 안드로이드 앱
- `tests/rules.test.cjs`: 카드·번호·벌칙·차례·종료 규칙 검사
- `.github/workflows/build-apk.yml`: GitHub에서 APK를 만드는 자동화

로컬 규칙 검사: `node tests/rules.test.cjs`

Android 빌드: Java 17, Gradle 8.9, Android SDK 35가 준비된 환경에서 `cd android && gradle :app:assembleDebug`

이 앱은 광고나 회원가입 없이 오프라인으로 작동하며, 외부 인터넷 접근 권한을 요청하지 않습니다.
